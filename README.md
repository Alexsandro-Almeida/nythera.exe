# Nythera: Echoes of the Fallen Stars — Demo

Instaladores da demo gratuita de **Nythera**, um RPG de ação em pixel art 2.5D. Um projeto independente da Express Games.

**Baixe a versão mais recente em [Releases](../../releases/latest)** ou pelo site oficial: https://nytherawebsite.vercel.app/#demo

- Windows 10 ou 11, 64 bits
- Português (Brasil) e inglês
- Grátis, sem cadastro

Se o Windows SmartScreen avisar "o Windows protegeu o computador", clique em **Mais informações** e depois em **Executar assim mesmo**. Somos um estúdio independente e o instalador ainda não tem certificado digital pago. Baixe apenas por este repositório ou pelo site oficial.
